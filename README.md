# live-ideas

**Current product working name:** Live Lyrics  
**Current V0 use case:** ultra-low-friction lyric fragment capture on iPhone.

```text
Drafts on iPhone
→ ↗
→ fixed Miro Board
→ one Sticky Note
```

Successfully sent fragments are also kept in a local read-only **Fragments** history.

## Security

Real Miro credentials and private Board IDs never belong in Git. Store them in Drafts Credential storage on the device.
